# Resume Builder (Offline)

## Run
1. Extract `ResumeBuilder_Project.zip`.
2. Open `index.html` in Chrome, Edge, or Firefox. No installation or Wi-Fi is required.
3. Fill the form. The A4 resume preview updates live.
4. Use the template dropdown to choose Classic, Professional, or Modern.
5. Drag the resume sections to reorder them.
6. Click **Export / Print PDF**, choose **Save as PDF**, and select **A4** paper.
7. Use **Save data** to download JSON. Use **Load data** to restore it later.

## Files
- `index.html`: UI and resume sections
- `style.css`: responsive layout, templates, A4 print styles
- `script.js`: live preview, template switching, drag/drop, JSON save/load, print

## Assignment checklist
- Live A4 preview: included
- 3 distinct templates: included
- Drag-and-drop section ordering: included
- PDF export: browser print-to-PDF, selectable text
- Save and load JSON: included, including template and section order
- Long resumes: print layout supports multiple pages; test with your own content
- Wi-Fi off: works locally without external libraries/CDNs

Tip: In the print dialog, turn off browser headers/footers if you want a clean resume.
